# How do I change a user's permissions?

Go to **Settings → User Management** and find the user whose permissions you want to change.

1. **Open the user's details**

   Select **Edit** next to the user.

2. **Update permissions**

   Under **Permissions**, select or clear the required **Write**, **Read**, and **Delete** permissions for each module.

3. **Save the changes**

   After updating the permissions, select **Save**.

![Change User Permissions](/images/faqs/change-user-permissions.png)
*Caption: User permissions can be updated from the Edit User screen.*

> **[Note]** Changing a user's permissions controls which features and actions they can access in MediFlux.
