# How do I change or update my password?

Update the password for the **main account** from **Profile**, or change passwords for other users from **User Management**.

---

## Update password for the main account

1. Click your profile avatar (top-right) and select **Profile**.
2. On the Profile page, click **Edit Profile**.
3. Enter the new password in **Password** and again in **Confirm Password**.
4. Click **Update**.

## Update password for another user

This action is available to **Admin** users only.

1. Go to **Settings → User Management**.
2. Find the user in the **Store Users** list.
3. Click **Edit**.
4. Update the password and save.

In the **Store Users** table, locate the user row and click **Edit** under **Actions** to open their profile dialog and enter new credentials.

---

> **[Note]** If you forgot your password and cannot sign in, use How do I reset my password?.
