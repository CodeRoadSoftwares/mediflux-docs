# How do I return a sale?

You can return a completed sale directly from **Sales → Sales List**.

1. **Select the sale**

   Find the sale you want to return and select the three-dot menu (⋮) on its row. Choose **Return Sale**.

2. **Enter return details**

   Review the customer name, sale number, and outstanding balance.

   Select whether a refund was initiated:

   - **Yes**: Enter the refund amount and, optionally, a receipt number.
   - **No**: Select this if no refund is being given.

3. **Confirm the return**

   Select **Return Sale** to confirm.

Click **Return Sale** to confirm the return (or **Cancel** to exit without changes); a **Sale returned successfully!** toast confirms the return, and the transaction is recorded under **Returned Sales**.

> **[Warning: Important]** Returning a sale cannot be undone. All drugs in the sale are added back to inventory immediately. Make sure the details are correct before confirming.
