# How do I make an NRx or H1 sale?

NRx and H1 sales use the same **Add Sale** flow as a regular retail sale. The drug **Type** (`NRx` or `H1`) is set automatically from the drug master.

---

## Steps

1. Go to **Sales → Add Sale** (or use the **+** button and select **Add Sale**).
2. Add the customer if needed.
3. Search or scan the drug and add it to the bill.
4. Check the **Type** column in the drug table. It will show `NRx` or `H1` based on how the drug is configured.
5. Complete payment details and click **+ Add** to finalise the sale.

![Drug Type column](/images/faqs/nrx-h1-type-column.png)
*Caption: Type column in the Add Sale drug table showing Rx, NRx, or H1.*

---

> **[Note]** Make sure the drug is correctly marked as NRx or H1 in the drug master. If the Type is wrong, update the drug profile first.
