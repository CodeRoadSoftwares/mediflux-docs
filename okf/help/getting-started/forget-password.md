# How do I invite my team?

Invite staff from **Settings → User Management**. Each person gets their own login so you can control what they can see and do.

1. Open **Settings**, then **User Management**.

2. Select **Add user** and enter their name, email, and role.

3. Save. They will receive an invite to set a password and sign in.
