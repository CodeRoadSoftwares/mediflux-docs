---
title: How do I change a user's permissions?
description: Update the permissions assigned to a user in MediFlux.
tags: [account, users, permissions, user-management]
related:
  - /docs/account/user-management
---

Go to **Settings → User Management** and find the user whose permissions you want to change.

<Steps>

<Step title="Open the user's details">

Select **Edit** next to the user.

</Step>

<Step title="Update permissions">

Under **Permissions**, select or clear the required **Write**, **Read**, and **Delete** permissions for each module.


</Step>

<Step title="Save the changes">

After updating the permissions, select **Save**.

</Step>

</Steps>

  src="/images/faqs/change-user-permissions.png"
  title="Change User Permissions"
  description="User permissions can be updated from the Edit User screen."
/>

<Callout type="note">
Changing a user's permissions controls which features and actions they can access in MediFlux.
</Callout>
