---
title: How do I remove a user?
description: Deactivate a user to prevent them from accessing your MediFlux account.
tags: [account, users, user-management]
related:
  - /docs/account/user-management
---

To remove a user's access to your MediFlux account, **deactivate the user**.

<Steps>

<Step title="Open User Management">

Go to **Settings → User Management** and find the user you want to remove.

</Step>

<Step title="Edit the user">

Select **Edit** next to the user's name.

</Step>

<Step title="Deactivate the user">

Enable **Deactivate User** and select **Save**.

</Step>

</Steps>

<Figure
  src="/images/faqs/remove-user.png"
  title="Deactivate User"
  description="Deactivate User option in the user settings."
/>

<Callout type="note">
Deactivating a user logs them out of any active session and prevents them from logging in to MediFlux. The user's account is not permanently deleted.
</Callout>
