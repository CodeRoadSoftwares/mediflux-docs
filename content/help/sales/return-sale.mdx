---
title: How do I return a sale?
description: Return a completed sale from the Sales List and record any applicable refund.
tags: [sales, returns, billing]
related:
  - /docs/sales/returned-sales
---

You can return a completed sale directly from **Sales → Sales List**.

<Steps>

<Step title="Select the sale">

Find the sale you want to return and select the three-dot menu (⋮) on its row. Choose **Return Sale**.

</Step>

<Step title="Enter return details">

Review the customer name, sale number, and outstanding balance.

Select whether a refund was initiated:

- **Yes**: Enter the refund amount and, optionally, a receipt number.
- **No**: Select this if no refund is being given.

</Step>

<Step title="Confirm the return">

Select **Return Sale** to confirm.

</Step>

</Steps>

  src="/images/faqs/return-sale.png"

/>

<Callout type="warning" title="Important">
Returning a sale cannot be undone. All drugs in the sale are added back to inventory immediately. Make sure the details are correct before confirming.
</Callout>
